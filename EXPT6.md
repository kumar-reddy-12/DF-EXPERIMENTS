# 4. Analyze the File System

Open **Command Prompt** and navigate to the directory where Sleuth Kit is installed.

---

## 4.1 Identify the File System with `fsstat`

The `fsstat` command provides information about the file system contained in the disk image.

Run:

```bash
fsstat [image_file] > filesystem_info.txt
```

Example:

```bash
fsstat "4Dell Latitude CPi.E01" > filesystem_info.txt
```

The output contains information about the structure and characteristics of the file system.

---

## 4.2 List Partitions with `mmls`

The `mmls` command is used to identify partitions present within the disk image.

Run:

```bash
mmls [image_file] > partitions.txt
```

Example:

```bash
mmls "4Dell Latitude CPi.E01" > partitions.txt
```

The output is stored in:

```text
partitions.txt
```

This helps identify the partition layout of the forensic image.

---

## 4.3 List Files and Directories with `fls`

The `fls` command can recursively list files and directories from the file system.

Run:

```bash
fls -r [image_file] > file_list.txt
```

Example:

```bash
fls -r "4Dell Latitude CPi.E01" > file_list.txt
```

The output contains file and directory information along with associated metadata.

---

# 5. Recover Deleted Files

## Use `icat`

The `icat` command can be used to extract a file from the forensic image using its inode number.

First, identify the required inode from the output generated by `fls`.

Run:

```bash
icat [image_file] [inode_number] > [output_file]
```

Example:

```bash
icat "4Dell Latitude CPi.E01" [inode_number] > recovered_file
```

Replace:

```text
[inode_number]
```

with the actual inode number identified during the file-system analysis.

The recovered file is saved to the specified output file.

# 6. Analyze File Metadata

## Use `istat`

The `istat` command provides detailed metadata about a specific file.

Run:

```bash
istat [image_file] [inode_number] > metadata_info.txt
```

Example:

```bash
istat "4Dell Latitude CPi.E01" [inode_number] > metadata_info.txt
```

The metadata can include information such as:

* File size
* File timestamps
* Allocation status
* File-system information

# 7. Timeline Analysis

Timeline analysis can be used to examine file activity according to timestamps.

## 7.1 Generate Body File

Use `fls` to generate a body file.

Run:

```bash
fls -m / -r [image_file] > body.txt
```

Example:

```bash
fls -m / -r "4Dell Latitude CPi.E01" > body.txt
```

---

## 7.2 Generate Timeline

Use `mactime` to generate the timeline.

Run:

```bash
mactime -b body.txt > timeline.txt
```

The generated file is:

```text
timeline.txt
```

The timeline contains **MAC timestamps**:

* Modified
* Accessed
* Changed

These timestamps help investigators understand file activity over time.
